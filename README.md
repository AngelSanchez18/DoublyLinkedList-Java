# Lista Doblemente Ligada en Java (Manual vs. Framework)

Este repositorio contiene dos implementaciones distintas de una **Lista Doblemente Ligada** (*Doubly Linked List*) en Java.
---
## Objetivos del Proyecto
- Comprender la estructura interna y la lógica de punteros en una lista doblemente ligada.
- Comparar el rendimiento y complejidad entre una estructura propia y el Framework de Colecciones de Java (`java.util.LinkedList`).
- Aplicar buenas prácticas de programación orientada a objetos (POO) y organización de paquetes.
